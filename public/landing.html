Flaike checks a GitHub repository and writes down whether changes were looked at, whether a review was required, and whether tests had to pass before the change went in.

What it checks

Was it reviewed

For each change that went in, Flaike lists who looked at it, or that nobody did.

Was a review required

It checks whether the main branch actually requires a review before a change can be merged.

Can the rule be skipped

It notes if an admin can bypass the review, and whether tests and force-push rules are weak.

How it works

1. Ask

You send a request. You do not pay on this page.

2. We look

We see what you need and whether it fits.

3. You get a login

If it fits, you get a username and password and can run the check yourself.
